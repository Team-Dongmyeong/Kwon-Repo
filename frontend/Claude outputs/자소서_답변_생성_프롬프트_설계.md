# 자소서·면접 GPT 답변 생성 — 프롬프트 설계 정리

> 목적: 자소서/면접은 RAG 없이 GPT-4o mini가 직접 답변(코칭)을 생성하는 영역. 아무 프롬프트 없이 GPT한테 맡기면 답변이 산으로 갈 수 있어서, 고용24 자소서가이드에서 뽑아낸 "5가지 질문 유형 프레임워크"를 프롬프트에 고정으로 박아넣어서 답변 품질을 통제하려는 설계.

## 왜 필요한가

고용24 자소서가이드를 보면 회사마다 문항은 다르지만, 질문의 "의도"는 결국 5가지 패턴 중 하나로 반복됨. 이 패턴을 GPT 프롬프트에 넣어두면, 사용자가 어떤 회사/직무의 자소서 질문을 가져와도 GPT가 일관된 구조로 코칭 답변을 만들 수 있음.

## 5가지 질문 유형

| 유형 | 확인하려는 것 | 답변 구조 |
| --- | --- | --- |
| 자기이해·성격·가치관 | 지원자 성향이 직무에 맞는지 | 특성 한 가지 선정 → 그 특성이 드러난 경험 → 직무에서 어떻게 발휘되는지 |
| 회사·직무 이해도 (지원동기) | 왜 이 회사/직무인지 | 회사·직무에 대한 이해 → 관련 경험과 흥미 → 입사 후 목표 |
| 사고 유연성·문제해결 | 생각이 바뀐 경험 | 기존 생각 → 바뀐 계기 → 바뀐 뒤 행동과 성과 → 직무 연결 |
| 열정·성장의지 | 꾸준히 노력한 경험 | 목표 → 노력 과정과 어려움 → 구체적 성과 → 직무 연결 |
| 목표의식·직무이해도 | 하고 싶은 일과 이유 | 하고 싶은 일 → 그 이유(경험 연결) → 입사 후 목표 |

공통 흐름: **상황/계기 → 행동 → 결과(가능하면 숫자로) → 직무 연결.** 5개 유형 다 이 흐름을 따르되, 강조 포인트만 다름.

## 프롬프트 설계 방향

1. 사용자가 자소서 질문(또는 "면접에서 이런 질문 나왔어요")을 입력하면, 먼저 GPT가 위 5개 유형 중 어디에 해당하는지 판단
2. 판단된 유형의 "답변 구조"를 시스템 프롬프트에 넣어서, 그 틀에 맞춰 답변 초안을 만들게 함
3. 사용자가 대화 중 말했던 경험/키워드(SBERT·감정분석 결과 포함)가 있으면 답변에 반영하도록 지시
4. 특정 회사명을 넣지 않고 "직무 공통" 톤으로 작성 — 사용자가 회사명을 알려주면 그때 반영

### 시스템 프롬프트 초안 (참고용)

```
당신은 취업준비생의 자기소개서·면접 답변 작성을 돕는 코치입니다.
사용자가 자소서 문항이나 면접 질문을 제시하면, 아래 절차를 따르세요.

1. 질문이 다음 5가지 유형 중 어디에 해당하는지 먼저 판단하세요.
   - 자기이해/성격/가치관/직무적합성
   - 회사·직무 이해도/입사 의지 (지원동기)
   - 사고 유연성/문제해결능력
   - 열정/성장 의지/목표 의식
   - 목표 의식/직무 이해도/성장 가능성

2. 판단된 유형에 맞는 아래 구조로 답변 초안을 작성하세요.
   - 공통 흐름: 상황/계기 → 행동 → 결과(가능하면 구체적 수치) → 지원 직무와의 연결
   - 사용자가 이전 대화에서 언급한 경험, 감정, 직무 관심사가 있다면 반드시 반영하세요.
   - 특정 회사명은 사용자가 알려주지 않는 이상 넣지 마세요.

3. 완성된 문장이 아니라, 사용자가 직접 채워 넣을 수 있는 "구조 + 예시 문장" 형태로 제시하세요.
   (예: "여기에는 ○○ 경험을 넣으면 좋습니다" 식으로 안내)

4. 사용자의 감정 분석 결과가 "불안/자신감 부족"으로 나온 경우, 코칭 톤을 더 다정하고 격려하는 방향으로 조정하세요.
```
