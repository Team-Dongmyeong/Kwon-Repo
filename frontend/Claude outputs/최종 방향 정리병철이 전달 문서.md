## 최종 방향 정리

1. RAG는 역량부족·취업진로 2개만 먼저 구축. 면접·자소서는 RAG 없이 GPT가 바로 답변 생성 (감정분석 결과 같이 활용).
2. 남는 리소스는 (a) IT/SW 말고 다른 직무 커버리지 넓히기, (b) 아래 공개 데이터로 보강하기에 씀.
3. 논문에는 "4개 영역을 사실 기반(RAG) / 코칭 기반(GPT 생성)으로 나눠서 처리했다"는 논리를 적음. 논문 제목("지능형 피드백 시스템")과도 잘 맞고, 그냥 LLM 쓰는 거랑 다른 점으로 내세울 수 있음.

## 부록 — 병철이 조사해줄 것 (쉬운 버전)

**1. 임금직업포털(Workpedia) — 이거 제일 먼저 봐줘**

정부에서 운영하는 사이트인데, 직업 하나하나마다 "하는 일 / 필요 자격증·기술 / 관련학과 / 평균연봉 / 전망"을 정리해둠. 이게 우리가 이미 만든 역량부족·취업진로 표랑 항목이 거의 똑같음. 그리고 특정 회사 공고 아니라 직업 자체 정보라 오래 써도 안 낡음.

- 링크: https://www.wagework.go.kr (직업정보 검색)
- 할 일: 우리가 다루는 대분류/중분류 직무 하나씩 검색해서, "하는 일/자격/기술/학과/연봉/전망" 내용을 우리 표 형식(역량부족·취업진로 컬럼)에 맞춰 옮겨 적기. PDF 다운로드도 되니까 그거 받아서 정리해도 됨.

**2. 고용24 "직무별 자소서 작성가이드" — 이건 데이터로 안 만듦, 링크만 안내**

(예전 "워크넷"은 서비스 종료됐고 지금은 "고용24"로 통합됨)

여기 있는 자소서 가이드는 특정 회사의 특정 채용공고에 맞춘 내용이라(예: "OO회사 2026 하반기 채용"), 공고 끝나면 못 씀. 그래서 이건 데이터로 정리할 필요 없고, 그냥 사용자한테 "더 자세한 건 여기서 확인하세요" 하고 링크만 보여주는 식으로 처리하기로 함. (자소서 질문 유형 5가지 패턴은 경민이 따로 정리해서 프롬프트에 넣을 예정 — 병철이 이거 조사 안 해도 됨)

- 링크: https://www.work24.go.kr/wk/r/d/1150/retrieveSelfintroWriteGuideViewList.do

**3. NCS(국가직무능력표준) "직업기초능력"**

정부가 "이 직업엔 이런 능력이 필요하다"를 표준화해서 정리한 자료. 우리 "역량부족" 데이터(자격증/기술/필요지식)랑 비슷해서, 아직 안 채운 직무 카테고리 채울 때 참고하면 좋음.

- 링크: https://www.ncs.go.kr/th03/TH0302List.do?dirSeq=121
- 할 일: 우리가 다루는 대분류/중분류에 맞는 항목 찾아서 "역량부족" 표 형식(자격증/기술/학과/필수지식)에 맞게 정리

**4. (추가) NCS직업기초능력검사 — 자가진단 사이트**

NCS 능력을 실제로 테스트해볼 수 있는 공개 설문 사이트. 나중에 사용자용 "역량 진단 설문" 만들 때 문항 구성 참고용으로 쓰면 됨.

- 링크: https://job.kosmes.or.kr/sportSvc/ncsInspctInfo/info.do

**우선순위: 1번(임금직업포털) → 3번(NCS) → 4번. 2번(고용24)은 조사 안 해도 됨.**
